How routing works: When a user types @bot <command> [text], the first matching trigger selects the route. If the text contains a GitHub URL or the words github/gh, the github tracker override is used (e.g. ai-gh-implement). If it contains a Jira/Bitbucket URL or the word jira/bitbucket, the jira override is used. Otherwise the org DefaultTracker setting applies, falling back to the Default Job Type. Trailing text is bound to the ID Variable param (e.g. a PR URL or issue number). Fixed params are merged into every job submission — their meaning is up to the job container. {{ if $.Admin }} Edit the SlackRoutes system config to add or change routes. Changes are picked up automatically within 30 seconds — no restart needed. {{ end }}
